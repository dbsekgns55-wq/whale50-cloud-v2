Whale50 V4.1 | 접근 제한 대응

1. Binance 주식 무기한 선물 API가 HTTP 451을 반환하면 해당 종목이 미상장이라는 뜻이 아닙니다.
2. 이때 공식 지원이 허용되는 Binance API 이용을 우회하지 않고 미국 주식 정규장 Yahoo 시세로 대체합니다.
3. 화면에서 "미국 주식 정규장 대체 · 24/7 아님" 문구를 확인하세요.
4. Yahoo 서비스가 차단되거나 제한되면 그 오류를 표시하고 과거 데이터를 지우지 않습니다.
5. 이전 Binance BINEQ: 기록과 Yahoo STOCK: 기록은 데이터베이스에서 독립 저장됩니다.
6. 수수료/슬리피지/펀딩비 미반영. 롱/숏 %는 지표 점수이지 수익 확률이 아닙니다.
7. 기존 data/whale50.sqlite3 및 config.json 백업 후 프로그램 파일만 교체하세요.
8. 클라우드에서는 GitHub 저장소 루트에 패치 파일을 덮어쓰고 Actions의 Run workflow로 실행합니다.
9. GitHub Pages는 별도 주소 변경 없이 기존 URL을 사용합니다.
10. 업데이트 이후 기존 24시간 Binance 데이터의 매매 가능 여부는 별도 확인이 필요합니다.
